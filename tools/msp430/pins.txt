# GDB simulator (tools/msp430/msp430.py, VERIFY-096, VERIFY-097). Each line:
# the test, the memory models (all, small, large), the build types (all, or
# a list of Debug, Release, RelWithDebInfo and MinSizeRel), and what the
# test does there: "not-built"; "fails N", N the lines of its output that
# begin with FAIL; or "times-out", stopped at the script's PINNED_TIMEOUT.
# A test no line names must pass. The lines are VERIFY-096's run 1, at both
# models and each build type; the three tests whose own arithmetic failed
# at a 16-bit int (lifetime_test, random_test, compare_test) were fixed
# instead, as the author chose (VERIFY-097). diag_test and log_test, which
# timed out inside newlib's tmpfile(), run since VERIFY-098 with the
# tmpfile() of tools/msp430/tmpfile.c, a stream in memory.
#

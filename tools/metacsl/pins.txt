# with properties of the unit this run does not prove (its loop
# invariants, its callees' contracts), which the unit's proof job does.
#
# Each function here but one calls through a pointer its caller passed,
# and WP cannot know what the function pointed to does:
#   - region_end calls each cleanup hook registered on the region, which
#     may be free (heap_raw) or call mem_free (heap_wrappers);
#   - option's and result's combinators (and_then, combine_with, eq,
#     filter, map, map_err, or_else) call the function they are given,
#     and vec_int_to_stringbuf_cb its formatting callback: one may call
#     contract_set_handler (handler_kept).
# The library's own code calls neither; a caller's function may.
#
# The one is vec_int_fill in the vec unit (handler_kept; run 1c). That
# unit is preprocessed without -CC, and fill's loop, in vec's macro, loses
# its annotations, its loop assigns among them (6 · Proofs: data/'s "fill
# macro-body-loop cluster"): WP then cannot bound what the loop writes.
# The stack unit, preprocessed with -CC, keeps them, and proves the check
# under them ("Partially proven").
